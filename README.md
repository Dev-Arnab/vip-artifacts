# MSU VIP Artifacts

A living catalog of manuscripts, software, and presentations produced by our Vertically Integrated Projects (VIP) team at Michigan State University.

Artifacts are grouped by semester, then by type. Within each category, entries are numbered. Put your name before the title so teammates can see who contributed what. Each entry should include a short description and a link to the artifact.

<details>
<summary><strong>How to add your work</strong></summary>

<br>

Copy a card below and fill it in. Keep numbering sequential within that category (`1.`, `2.`, `3.`, …).

```html
<tr>

<br><br>
```

<tr>
<td valign="top" width="100%">

<strong>1. Dev Jyoti Ghosh Arnab — sarpanel</strong>
<br><br>
Python package that turns Sentinel-1 SAR archives into analysis-ready pixel time-series panels. Given an area of interest and date range, it searches ASF, processes scenes with ESA SNAP via pyroSAR, and writes per-pixel Parquet tables with backscatter, geometry, and provenance retained.
<br><br>
🔗 <a href="https://github.com/Dev-Arnab/sarpanel">GitHub Repository</a>
