# MSU VIP Artifacts

A living catalog of manuscripts, software, and presentations produced by our Vertically Integrated Projects (VIP) team at Michigan State University.

Artifacts are grouped by semester. Under each semester, entries are organized by type. Each entry includes a short title, a brief description, and a link to the artifact.
